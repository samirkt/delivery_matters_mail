Apartment Name Card Generator

This tool turns a spreadsheet of residents into printable mail box name cards. Follow the four steps below.

1Choose your spreadsheet file

Click "Choose File" and pick the file with your resident list. Excel files (.xlsx) and .csv files both work.

2Are the blue badges in the correct spot?

This table shows what was read from your file. The blue badges show which columns will be used on the cards. If a badge is missing or in the wrong place, fix it in Step 3.

The preview will appear here once you choose a file.

Change the card order

Choose which column to sort by. The table and the printed cards will follow this order.

3Fix columns (if needed)

Use the dropdowns below to tell the tool which column holds each piece of information. The badges in Step 2 will move as you change them.

Waiting for a file — finish Step 1 first.

Need to split a column? (for example, one "Name" column into first and last)

Pick the column to split and the character that separates the two parts, then click "Split". Two new columns will be added, and you can select them in the boxes above.

4Create your name cards

Click the blue button. A PDF file called "name_cards.pdf" will be saved to your Downloads folder. Print it and cut along the gray lines.
